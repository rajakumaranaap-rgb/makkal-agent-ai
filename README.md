## 💡 The Core Philosophy: Maximum 2-3 Step Interactive Flow (Built for Rural & Illiterate Citizens)

### Why 2-3 Steps?
Rural and semi-urban citizens in India face a significant digital divide. Long, multi-paragraph text walls filled with bureaucratic statutes, government rules, and complex application processes cause confusion and abandonment. Many users are semi-literate, elderly, or daily-wage workers who communicate via **voice notes** or simple **taps**.

SIA implements a **Strict Maximum 2-to-3 Step Interactive Architecture**:
- **Zero Text Walls:** The bot never outputs long essays or multi-page rulebooks.
- **Maximum 3 Buttons per Prompt:** Every menu presents at most 3 clear, pictorial choices so the user is never overwhelmed.
- **Immediate Concrete Fulfillment:** Tapping any button immediately generates the final asset—an official sealed PDF petition, an instant herbal bio-cure prescription, an auto booking OTP, a grocery order dispatch, or a single CBT quiz question.

## ❓ Frequently Asked Questions (FAQ) for Judges & End-Users

### Q1: What is SIA (Super-Intelligent Assistant) / Namma Ooru SuperApp?
**A:** SIA is a sovereign, multimodal, vernacular AI assistant built for India's 800 million citizens who live outside major metropolitan cities. It unifies agriculture, cattle trading, grocery commerce, auto/tractor transit, food delivery, government certificates (*Patta/Chitta*), MLA/MP petitions, and school education into a single touchpoint on WhatsApp and the Web with zero app installations.

### Q2: Why did you choose WhatsApp native ingress instead of an app store download?
**A:** The average rural Indian smartphone costs under ₹10,000 and has only 32 GB or 64 GB storage. Installing 12 separate apps rapidly exhausts device storage and causes frequent crashes. Furthermore, complex English logins and passwords create high digital literacy barriers. Since over 500 million Indians already use WhatsApp daily, SIA brings AI directly to where citizens live.

### Q3: How does a citizen interact on WhatsApp (`+91 824 881 8077` ⇄ `+91 63810 29380`)?
**A:** A citizen simply opens WhatsApp and messages our verified hotline **`+91 63810 29380`** (Aishlee Technology). They can send a Tamil voice note, snap a photo of a diseased plant, or tap native interactive buttons (`நம்ம ஆட்டோ`, `விவசாயம்`, `மனு PDF`). The Meta AI agent understands colloquial Tamil, classifies the intent, and responds in under 2 seconds.

### Q4: How does the dual-surface Web App Co-Pilot work?
**A:** When a user visits `https://regulatory-stack-counter-lady.trycloudflare.com/?unlocked=1`, the Web App acts as a high-speed command center for village Common Service Centers (CSC) and merchants. Connected via high-speed WebSockets, it mirrors the WhatsApp session in real time, rendering Mandi charts, driver GPS locations, and printable PDF documents.

### Q5: How does SIA diagnose crop diseases using Meta AI?
**A:** When a farmer snaps a photo of a leaf, **Meta SAM 3.1** running on Modal Serverless GPU segments the necrotic lesion areas. The system cross-references Tamil Nadu Agricultural University (TNAU) protocols to recommend chemical (Tricyclazole 75 WP @ 1g/L) and organic remedies (Pseudomonas fluorescens @ 2.5g/L), along with required water volumes per acre.

### Q6: How does RedTaxi manage auto-rickshaw and tractor rentals without surge pricing?
**A:** Unlike corporate aggregator apps that charge 30% commissions and apply unpredictable surge pricing, RedTaxi operates on fixed government meter rates (₹40 base fare, ₹12/km). When an auto is requested, the system verifies driver credentials, generates a secure 4-digit **Start OTP (e.g., `6395`)**, and directly connects the passenger. It also lets farmers schedule 45HP rotavator tractors for hourly field plowing @ ₹850/hr.

### Q7: How does the AnyROR Patta/Chitta extraction work?
**A:** When a citizen provides their Survey Number (e.g., `142/3A`), SIA queries the land registry database, validates ownership records, and extracts Patta records. It provides a 3-stage live approval tracker (Village Administrative Officer ➔ Revenue Inspector ➔ Tahsildar digital signature) and delivers a court-ready petition PDF.

## 🚀 Quickstart & Local Execution

### Prerequisites
- Python 3.10+ (Tested on Python 3.12)
- Meta Model API Key (from [dev.meta.ai](https://dev.meta.ai))
- Baseten API Key (for Open-Weight Award)

### 1. Clone & Configure
```bash
git clone https://github.com/rajakumaranaap-rgb/makkal-agent-ai.git
cd makkal-agent-ai
cp .env.example .env
```

### 2. Install Dependencies
```bash
python -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

### 3. Launch Application Server
```bash
python -m uvicorn app:app --host 0.0.0.0 --port 8001 --reload
```
Open **`http://localhost:8001/?unlocked=1`** (or your live Cloudflare tunnel URL) to access the interactive portal.
