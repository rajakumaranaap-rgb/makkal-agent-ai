## 💡 The Core Philosophy: Maximum 2-3 Step Interactive Flow (Built for Rural & Illiterate Citizens)

### Why 2-3 Steps?
Rural and semi-urban citizens in India face a significant digital divide. Long, multi-paragraph text walls filled with bureaucratic statutes, government rules, and complex application processes cause confusion and abandonment. Many users are semi-literate, elderly, or daily-wage workers who communicate via **voice notes** or simple **taps**.

SIA implements a **Strict Maximum 2-to-3 Step Interactive Architecture**:
- **Zero Text Walls:** The bot never outputs long essays or multi-page rulebooks.
- **Maximum 3 Buttons per Prompt:** Every menu presents at most 3 clear, pictorial choices so the user is never overwhelmed.
- **Immediate Concrete Fulfillment:** Tapping any button immediately generates the final asset—an official sealed PDF petition, an instant herbal bio-cure prescription, an auto booking OTP, a grocery order dispatch, or a single CBT quiz question.

## 🚀 Quickstart & Local Execution

- Python 3.10+ (Tested on Python 3.12)
- Meta Model API Key (from [dev.meta.ai](https://dev.meta.ai))
- Baseten API Key (for Open-Weight Award)

### 1. Clone & Configure
```bash
git clone https://github.com/rajakumaranaap-rgb/makkal-agent-ai.git
cd makkal-agent-ai
cp .env.example .env
```

### 2. Install Dependencies
```bash
python -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

### 3. Launch Application Server
```bash
python -m uvicorn app:app --host 0.0.0.0 --port 8001 --reload
```
Open **`http://localhost:8001/?unlocked=1`** (or your live Cloudflare tunnel URL) to access the interactive portal.
